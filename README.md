# Papertrail

Papertrail is a macOS Markdown editor with a live preview, clickable document outline, highlighted code blocks, light/dark themes, recent files, full-text search, in-app updates, virtual file categories that never move documents, and support for Markdown, text, and JSON files.

Use **Prep for agent** after opening or saving a Markdown file to copy its full absolute path to the clipboard.

## Code structure

See [the architecture guide](docs/architecture.md) for process boundaries, module responsibilities, and extension points.

## Run it locally

```sh
npm install
npm start
```

## Sequence diagrams

Fence WebSequenceDiagrams source with `wsd` to render it in the preview. Use **Expand** to open the full-resolution diagram with zoom controls, or expand **Edit diagram source** beneath it to edit without leaving the preview.

````markdown
```wsd
Client->Server: Request
Server-->Client: Response
```
````

Rendering uses websequencediagrams.com and requires a network connection.

## In-app updates

Packaged builds check the public GitHub release feed at launch and every four hours. A release must include the matching `latest-mac.yml`, Intel and Apple-silicon ZIPs, and their blockmaps generated by the same build; the DMGs remain the manual installers.

Updater, renderer, and unhandled service errors automatically open **Diagnostics**. The same persistent logs can be reopened from the toolbar or View menu and copied for troubleshooting.

macOS requires every auto-updatable build to use the same valid Developer ID Application certificate. Ad-hoc signed builds can be downloaded manually but cannot install themselves.

## Make an installable macOS build

```sh
npm run package
```

This produces separate, smaller Apple-silicon (`arm64`) and Intel (`x64`) macOS installers in `dist/`. Choose the installer that matches the destination Mac, drag Papertrail to Applications, and use **Open** from Finder the first time because the local build is unsigned.

## Verify
